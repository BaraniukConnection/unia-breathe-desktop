# Unia Breathe — план переходу

Макет: [`design/unia-breathe.html`](../design/unia-breathe.html) (відкривається в будь-якому браузері).
Поточна робоча збірка лишається в `~/.config` (свій git) — це запасний варіант, поки Unia Breathe не готова.

---

## 0. Загальна ідея

| | Зараз (`~/.config`) | Unia Breathe |
|---|---|---|
| Верх екрана | одна суцільна смуга waybar | окремі скляні «бульбашки»: ліворуч, по центру, праворуч, між ними — шпалери |
| Низ екрана | нічого | док: 5 круглих обраних програм + стрілка меню |
| Меню програм | rofi (список) | скляна панель з плитками в папках, над доком |
| Сповіщення й керування | SwayNC | власна панель під бульбашкою статусу |
| Налаштування | кнопки в SwayNC, кожна відкриває окреме плаваюче вікно | окремий спецворкспейс: панель категорій зліва + програма праворуч |
| Сценарії | rofi-меню на Super+S | вікно «Столи та сценарії» з мініатюрами розкладок |
| Кольори | сіро-зелені `#8CC1AD` / `#08583A` | глибокий смарагд: тло `#0b2a26`, акцент `#10b981`, текст `#eaf6f0` |
| Шрифт / іконки | Roboto + Nerd Font | **Manrope**; іконки програм — справжні, значки інтерфейсу — **Material Symbols Outlined** |

**Скло скрізь однакове:** `rgba(8,30,25,.35)` + розмиття, тонка світла обвідка `rgba(255,255,255,.14)`, м'яка тінь.
Меню й спливаючі підказки щільніші — `.62`. Кути: бульбашки повністю круглі, вікна/панелі 20–28 px.

### Прийняті рішення (3 жовт. 2026)

1. Основа — **Quickshell**.
2. ОЗП/ВОЗП — **прибрати зовсім**.
3. Кнопки живлення — як у макеті (вимкнути, перезапуск, сон, вийти), без «змінити користувача».
4. Іконки — **справжні іконки програм** (у макеті були заглушки).
5. Пошук у меню — **додати**.
6. Календар — **Google Calendar**.
7. Девайси: Logitech Lift — лише загальні налаштування миші; Logitech G915 — підсвітка через OpenRGB;
   Wacom Intuos S (CTL-4100) — OpenTabletDriver.

### На чому збирати

Waybar + SwayNC + rofi цей макет не потягнуть: потрібні спливаючі вікна з календарем, обкладинкою треку,
плитки з перетягуванням, власні сторінки налаштувань. Потрібен «конструктор оболонки»:

| | **Quickshell** (рекомендую) | AGS / Astal |
|---|---|---|
| Звідки | офіційний репозиторій Fedora | Copr `sdegler/hyprland` |
| Мова | QML (+ трохи JS) | TypeScript/TSX + GTK4 CSS |
| Анімації, перетягування плиток | сильна сторона | можливо, але більше ручної роботи |
| Hyprland, MPRIS, PipeWire, сповіщення, Bluetooth | вбудовані модулі | вбудовані сервіси |
| Схожість з макетом (HTML/CSS) | стилі переписуються в QML | GTK CSS дуже схожий на CSS макета |

Рекомендую **Quickshell**: офіційний пакет (оновлюється разом із системою), плавні анімації як у макеті,
перетягування плиток «з коробки». Одна програма замінить waybar, SwayNC, rofi-меню і док.

Що лишається як є: Hyprland, hyprpaper/waypaper, hyprlock, hypridle, kitty, Thunar, скрипт сценаріїв
(його логіка збереження геометрії вікон точніша за ту, що в макеті).

## 1. Верхня смуга (замість Waybar)

```
[Сценарій · Dev] [Стіл · ①]          [ 3 жовт  20:41 ]  [▣ Назва треку ⏮ ⏸ ⏭]          [⌨ ua 🔊 34% ᛒ Lift 📶 Northtop] [🔔] [⏻]
```

- **Немає суцільної смуги.** Кожна група — окрема скляна пігулка висотою 44 px, відступ 16 px від верху і 20 px від краю.
  Вікна починаються під бульбашками (резерв зверху ~72 px).
- **Ліворуч:** дві бульбашки — «Сценарій» і «Стіл» (див. розділи 2–3).
- **Центр:** годинник (розділ 4) і трохи правіше — медіа (розділ 5).
- **Праворуч:** бульбашка статусу (розкладка, гучність, Bluetooth-пристрій, Wi-Fi), дзвіночок, кнопка живлення.
  - **Наведення** на будь-яку частину статусу показує підказку: повна назва розкладки / куди йде звук /
    список Bluetooth-пристроїв / мережа й сила сигналу.
  - **Колесо миші:** над гучністю — ±2 %, над розкладкою — перемкнути мову, над Bluetooth — інший пристрій.
  - **Клік** по статусу або дзвіночку — панель керування (розділ 6).
  - Дзвіночок: зірочка-позначка, коли є сповіщення; закреслений, коли «Не турбувати».
  - **⏻** — меню: Вимкнути, Перезавантажити, Сон, Вийти з сеансу.
- **Коли місця мало** (вузький Dell 1680 px), підписи ховаються поступово — лишаються лише іконки.
- **Одночасно відкрите лише одне спливаюче вікно**; клік по столу або Esc закриває його.

**Що зникає з поточного:** waybar повністю, окремі модулі Bluetooth/Wi-Fi (тепер у статусі).

## 2. Сценарії

- **Бульбашка «Сценарій · <назва>»** показує сценарій поточного столу.
  - Якщо ти змінив набір вікон після запуску — біля назви позначка «змінено».
  - Стіл без сценарію — «Власний».
- **Клік** → вікно «Столи та сценарії» (спільне з розділом 3), нижня половина:
  - картки сценаріїв з **мініатюрою розкладки** (кольорові прямокутники, як стоять вікна) і назвою;
  - клік по картці — відкрити сценарій на поточному столі;
  - права кнопка — «Відкрити на цьому столі» / «Видалити» (з можливістю «Повернути»);
  - «Зберегти сценарій» → поле назви (до 14 символів) прямо у вікні, без rofi.
- **Сценарій «Default»** — порожній стіл, видалити не можна.
- **Під капотом** лишається `scenario.py`: зберігає точну геометрію вікон і відновлює дерево поділів.
  Мініатюри малюються з тих самих збережених координат. Твій `OxygenDev.json` переїде без змін.

⚠️ **Відмінність від макета:** у макеті колесо миші над бульбашкою перемикає сценарій. Насправді це означало б
запуск і закриття програм від випадкового прокручування. Пропоную: колесо лише **гортає назви**,
а застосування — кліком.

## 3. Робочі столи

- **Бульбашка «Стіл · ①»** — номер поточного столу в кружечку.
  - **Колесо миші** — сусідній стіл (це безпечно, на відміну від сценаріїв).
  - **Клік** → те саме вікно «Столи та сценарії», верхня половина: ряд кружечків з номерами відкритих столів,
    поточний підсвічений, «+» — новий стіл. Підказка над кожним: сценарій і кількість вікон.
- **Правила:** до 9 столів; порожній стіл закривається, щойно з нього підеш (Hyprland так і робить);
  два столи живуть завжди — по одному на монітор (1 → DP-2, 2 → HDMI, як зараз у nwg-displays).
- **Вікна:** до 6 на стіл, ділять місце як зараз (dwindle). Відступи 10 px, скляні рамки, кути 20 px.

## 4. Годинник і календар

- **Бульбашка по центру:** дата («3 жовт.») + великий час «20:41».
- **Клік** → календар 328 px шириною:
  - назва місяця, стрілки ‹ › для перемикання місяців, сітка днів, сьогодні підсвічено;
  - внизу «Наступна подія» — назва і коли.

**Події — з Google Calendar** через «секретну адресу в форматі iCal» (Google Calendar → Налаштування календаря →
Інтеграція календаря). Скрипт раз на 15 хв завантажує її й віддає найближчі події.
- Тільки читання: з робочого столу події не створюються і не редагуються.
- Адресу ти сам вставиш у `~/.config/unia-breathe/calendar.url` — цей файл **не потрапляє в git**
  (адреса дає доступ на читання календаря, як пароль).
- Кілька календарів — по одній адресі на рядок.

## 5. Медіа

- **Бульбашка поруч із годинником:** маленька кругла обкладинка, назва треку бігучим рядком
  (якщо не влазить — їздить туди-назад), кнопки ⏮ ⏸ ⏭.
- Під бульбашкою — дрібно, **з якої програми звук** (Vivaldi, Spotify…).
- **Клік по обкладинці/назві** → медіацентр: назва + виконавець, велика обкладинка, великі кнопки керування,
  джерело звуку.
- Дані — з MPRIS (те саме, що зараз бачить SwayNC: YouTube у Vivaldi теж працює).
- Пропозиція (у макеті не описано): коли нічого не грає — бульбашка ховається.

## 6. Панель керування та сповіщень

Відкривається під бульбашкою статусу, ширина 448 px.

1. **Швидкі плитки** (великі, 76 px):
   - **Wi-Fi** — назва мережі під підписом, клік вмикає/вимикає;
   - **Bluetooth** — підключений пристрій (Lift), клік вмикає/вимикає;
   - поруч **6 місць для закріплених налаштувань** — будь-яку категорію з налаштувань (розділ 8) можна закріпити сюди.
2. **Гучність** — широкий повзунок-заливка з відсотками й кнопкою вимкнення звуку.
3. **Сповіщення** — список (іконка програми, заголовок, текст, час, ✕), кнопка «Не турбувати».
4. **Низ:** чотири круглі кнопки живлення (вимкнути, перезапуск, сон, вийти) + кнопка **«Відкрити налаштування»**.

**Що змінюється відносно поточного SwayNC:**
- кнопок Wi-Fi/Bluetooth/Звук/Дисплеї/Шпалери/Теми/Принтери тут більше немає — вони переїжджають у налаштування;
- плеєр переїжджає в медіа-бульбашку;
- перезапуск і вимкнення досі питають підтвердження (у макеті цього немає, але так безпечніше).

- ОЗП/ВОЗП прибираються повністю (скрипт VRAM теж).
- **Вибір Wi-Fi мережі:** у макеті плитка лише вмикає/вимикає. Додаю стрілку › на плитці — список мереж
  прямо в панелі.

## 7. Меню програм (док + плитки)

**Док** внизу по центру (376×106 px). **Ховається, як в Ubuntu:** зазвичай його не видно, а він виїжджає,
коли довести мишу до нижнього краю екрана (і ховається, щойно мишу відведено, а меню закрите).
- 5 круглих обраних програм (64 px), кольорові кола;
- під ними стрілка ⌃ — відкриває меню.
- Обрані додаються/прибираються через праву кнопку на будь-якій програмі.

**Панель меню** піднімається над доком, до 580 px заввишки:
- **Папки з плитками** у двох колонках (на вузькому моніторі — в одну). Стартові папки: «Щодня», «Творчість», «Корисне»,
  «Інше» (туди автоматично падає все несортоване).
- **Розміри плиток:** малий (просто іконка), середній 2×2, широкий 4×2, великий 4×4 — права кнопка міняє розмір.
- **Живі плитки** (середні й більші): Годинник, Календар, Галерея, Підказки — показують вміст, а не лише іконку.
- **Перетягування:** плитки між папками й місцями, цілі папки; проміжок між папками створює нову; назву папки можна змінити кліком.
- **Клавіатура:** Alt+Shift+стрілки рухають виділену плитку.
- Знизу: «Скинути розкладку» і перемикач **Плитки / Усі програми** (повний алфавітний список).
- Список програм береться з системних `.desktop`-файлів — усе встановлене з'явиться само.

- **Іконки — справжні іконки програм** (з теми іконок, як у `.desktop`-файлах). Material Symbols лишаються
  тільки для системних значків інтерфейсу (гучність, Wi-Fi, стрілки тощо).
- **Пошук:** відкрив меню і почав друкувати — замість плиток показується відфільтрований список програм,
  Enter запускає першу. Super+R відкриває меню одразу з полем пошуку. Rofi лишається для Wi-Fi-скрипта.

## 8. Налаштування (спецворкспейс)

**Як працює:**
- Окремий **спеціальний воркспейс `special:settings`** — виїжджає поверх поточного столу і ховається назад.
  Викликається **однією кнопкою**: Super+I (пропоную), «Відкрити налаштування» в панелі керування або плитка «Параметри» в меню.
- **Зліва — панель фіксованої ширини (304 px):** заголовок «Налаштування» + ✕, перемикач розділів
  **Основні / Кастомізація / Девайси**, список категорій (іконка, назва, яка програма відповідає).
- **Справа — програма займає решту місця.** Разом із панеллю виглядає як одне вікно.
- **Клік по категорії** запускає потрібну програму (або показує, якщо вона вже відкрита) і **ховає попередню**.
  Сховані програми не закриваються, а відкладаються — повернення до них миттєве.

**Категорії з макета і чим відкриваються:**

| Розділ | Категорія | Програма |
|---|---|---|
| Основні | Інтернет | nm-connection-editor |
| | Блютуз | **Overskride** (у макеті Blueman — лишаємо твій Overskride) |
| | Час і дата | власна сторінка (часовий пояс, синхронізація, 24-год формат) |
| | Звук | pavucontrol |
| | Дисплей | nwg-displays |
| | Розкладка | власна сторінка (мови, клавіша перемикання) |
| Кастомізація | Шпалери | waypaper |
| | Кольори | nwg-look (GTK); для Qt — qt6ct |
| | Прозорість | власна сторінка (прозорість вікон, розмиття) |
| | Вікна й межі | власна сторінка (відступи, рамки, заокруглення) |
| Девайси | Мишка (Logitech Lift) | власна сторінка: швидкість, прискорення, природне прокручування, ліва рука |
| | Клавіатура → мова | власна сторінка |
| | Клавіатура → підсвітка (G915) | OpenRGB ⬇ |
| | Принтери | system-config-printer |
| | Графічний планшет (Wacom Intuos S) | OpenTabletDriver ⬇ |

⬇ — ще не встановлено. **«Власна сторінка»** — для налаштувань самого Hyprland, де готової програми немає:
я зроблю прості сторінки з повзунками й перемикачами прямо в правій частині, а зміни записуватимуться в окремий
файл конфігу. Piper не потрібен — для Lift достатньо загальних налаштувань.

**OpenTabletDriver і Wacom:** OTD працює замість драйвера ядра `wacom` — при встановленні він вимикає його
(інакше обидва драйвери б'ються за планшет). Зате дає GUI: робоча область, прив'язка до монітора
(DP-2 чи HDMI), крива натиску, кнопки ExpressKeys. Ставиться RPM-пакетом із GitHub-релізу (у Fedora його немає,
а Flatpak-версія не може встановити потрібні udev-правила).

## 9. Порядок робіт

1. **Основа:** Quickshell, шрифти Manrope + Material Symbols, палітра, правила розмиття в Hyprland, структура репо
   і встановлення через симлінки в `~/.config` (з можливістю швидко повернутись до старої збірки).
2. **Верхня смуга:** бульбашки, статус з підказками й колесом, годинник, медіа. Waybar вимикається.
3. **Панель керування + сповіщення.** SwayNC вимикається.
4. **Столи та сценарії** (вікно, мініатюри, збереження).
5. **Налаштування** (спецворкспейс, панель категорій, перемикання програм).
6. **Власні сторінки налаштувань.**
7. **Док і меню програм** — найбільший шматок: плитки, папки, перетягування, живі плитки.
8. Перефарбування решти під палітру: kitty, рамки Hyprland, hyprlock, GTK-тема, Thunar.

Кожен етап — окремі коміти, після кожного все працює і можна користуватись.
